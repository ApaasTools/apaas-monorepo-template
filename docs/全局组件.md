# 全局组件

APAAS 平台提供了多个 UI 组件包，组件在应用启动时通过 `Vue.component()` 全局注册，无需手动 import 即可直接在模板中使用。

## 组件包概览

| 包名 | 说明 | 组件前缀 |
|------|------|---------|
| x-lib-ui | 核心业务 UI 组件库 | X |
| x-dcloud-ui | 分布式云 UI 组件库（x-lib-ui 超集） | X |
| x-extension | 扩展组件 | Extension / DynamicComponent |
| x-guard | 运维监控图表组件 | G |

> x-dcloud-ui 包含 x-lib-ui 的全部组件，额外增加了 `XDepartmentTag`、`XPersonSelect`、`XEditorLazy`、`XRichTextLazy` 等组件。

## 使用示例

```html
<template>
  <!-- 弹窗 -->
  <x-modal
    width="middle"
    :modal-visible="showModal"
    title="编辑信息"
    @on-ok="handleOk"
    @on-cancel="showModal = false"
  >
    <!-- 表单 -->
    <x-block-form :model="formData" :rules="rules" label-width="120px">
      <!-- 金额输入 -->
      <x-money-input
        :config-value="formData.amount"
```

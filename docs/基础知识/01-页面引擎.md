# 页面引擎 API 文档

> 包名：`@x-apaas/x-dcloud-page-engine`  
> 版本：4.0.8+  
> 入口：`lib/es/index.js`

## 概述

页面引擎是 APAAS 低代码平台的核心模块，提供表单、列表、布局、BI 看板的引擎能力，以及控制器、混入、常量、工具函数等基础设施。

---

## 一、引擎类

### FormEngine

表单引擎，负责表单的渲染、数据管理、校验和交互逻辑。

**引入方式：**
```js
import { FormEngine } from '@x-apaas/x-dcloud-page-engine';
```

**核心方法：**

| 方法 | 参数 | 返回值 | 说明 |
|------|------|--------|------|
| `initForm(config)` | `config: Object` - 表单配置 | `void` | 初始化表单 |
| `getFormData()` | 无 | `Object` | 获取当前表单数据 |
| `setFormData(data)` | `data: Object` - 表单数据 | `void` | 设置表单数据 |
| `validateForm()` | 无 | `Promise<Boolean>` | 校验表单 |
| `resetForm()` | 无 | `void` | 重置表单 |
| `refreshForm()` | 无 | `void` | 刷新表单（触发 REFRESH_FORM_KEY 事件） |

### ListEngine

列表引擎，负责列表页的数据加载、分页、筛选和展示。

**引入方式：**
```js
import { ListEngine } from '@x-apaas/x-dcloud-page-engine';
```

**核心方法：**

| 方法 | 参数 | 返回值 | 说明 |
|------|------|--------|------|
| `initList(config)` | `config: Object` - 列表配置 | `void` | 初始化列表 |
| `loadData(params)` | `params: Object` - 查询参数 | `Promise<Array>` | 加载列表数据 |
| `refreshList()` | 无 | `void` | 刷新列表数据 |

### LayoutEngine

布局引擎，负责页面布局的渲染和管理。

**引入方式：**
```js
import { LayoutEngine } from '@x-apaas/x-dcloud-page-engine';
```

### BiEngine

BI 看板引擎，负责数据可视化看板的渲染。

**引入方式：**
```js
import { BiEngine } from '@x-apaas/x-dcloud-page-engine';
```

## 六、XStore（状态管理）

基于简单的键值对模式的全局状态管理器，导出为单例实例。

**引入方式：**
```js
import XStore from '@x-apaas/x-dcloud-page-engine/lib/x-store';
```

**API：**

| 方法 | 参数 | 返回值 | 说明 |
|------|------|--------|------|
| `setState(key, value)` | `key: String` - 键名<br>`value: any` - 值 | `void` | 设置状态 |
| `getState(key)` | `key: String` - 键名 | `any` | 获取状态 |
| `deleteState(key)` | `key: String` - 键名 | `void` | 删除状态 |

**使用示例：**
```js
XStore.setState('currentUser', { name: '张三' });
const user = XStore.getState('currentUser');
XStore.deleteState('currentUser');
```

## 七、XEventBus（事件总线）

基于 `mitt` 的发布/订阅事件总线，导出为单例实例。

**引入方式：**
```js
import XEventBus from '@x-apaas/x-dcloud-page-engine/lib/x-event-bus';
```

**API：**

| 方法 | 参数 | 返回值 | 说明 |
|------|------|--------|------|
| `emit(key, ...args)` | `key: String` - 事件名<br>`...args: any` - 事件参数 | `void` | 触发事件 |
| `on(key, callback)` | `key: String` - 事件名<br>`callback: Function` - 回调函数 | `void` | 监听事件 |
| `off(key, callback)` | `key: String` - 事件名<br>`callback: Function` - 回调函数 | `void` | 取消监听 |

**使用示例：**
```js
// 监听事件
XEventBus.on('refreshForm', (data) => {
  console.log('表单已刷新', data);
});

// 触发事件
XEventBus.emit('refreshForm', { formId: '123' });

// 取消监听
XEventBus.off('refreshForm', handler);
```

## 九、插件安装

```js
import PageEngine from '@x-apaas/x-dcloud-page-engine';

Vue.use(PageEngine);
```

安装后可通过 `Vue.$pageEngine` 或组件内 `this.$pageEngine` 访问。

**导出列表：**
```js
export { FormLogicMixin, LayoutLogicMixin, ListLogicMixin };
export { BiEngine, FormEngine, LayoutEngine, ListEngine };
export { ButtonControl, ExtendControl, NetworkControl, RenderLogicControl, WidgetControl };
export { install, version };
```

# 规则引擎 API 文档

> 包名：`@x-apaas/x-lib-rule-engine`  
> 入口：`dist/index.d.ts`

## 概述

规则引擎是 APAAS 平台的核心计算模块，负责解析和执行业务规则表达式。支持函数注册、表达式解析、规则校验等能力。

---

## 一、RuleEngine（规则引擎）

规则引擎主类，采用单例模式。

**引入方式：**
```js
import RuleEngine from '@x-apaas/x-lib-rule-engine';
```

### 静态方法

| 方法 | 参数 | 返回值 | 说明 |
|------|------|--------|------|
| `getInstance()` | 无 | `RuleEngine` | 获取规则引擎单例实例 |

### 实例方法

| 方法 | 参数 | 返回值 | 说明 |
|------|------|--------|------|
| `getOrCreateSharedContext()` | 无 | `RuleRuntimeContext` | 获取或创建共享运行上下文 |
| `resetSharedContext()` | 无 | `void` | 重置共享运行上下文 |
| `clearAllCache()` | 无 | `void` | 清除所有缓存 |
| `registerContextMethod(functionName, ruleFunction)` | `functionName: String` - 函数名<br>`ruleFunction: IRuleFunction` - 规则函数 | `this` | 注册上下文方法（支持链式调用） |
| `registerContextMethods(functions)` | `functions: Array<IRuleFunction>` - 规则函数数组 | `this` | 批量注册上下文方法（支持链式调用） |
| `unRegisterContextMethod(functionName)` | `functionName: String` - 函数名 | `this` | 注销上下文方法（支持链式调用） |
| `executeRule(rule, executorUuid?)` | `rule: Rule` - 规则对象<br>`executorUuid?: String` - 执行器唯一标识 | `any` | 执行规则 |

**使用示例：**
```js
const engine = RuleEngine.getInstance();

// 注册自定义函数
engine.registerContextMethod('MY_FUNC', {
  functionName: 'MY_FUNC',
  execute: (...args) => args.reduce((a, b) => a + b, 0)
});

// 执行规则
const result = engine.executeRule(rule);
```

轻量级规则引擎，不依赖单例模式，适用于独立场景。

**引入方式：**
```js
import { SimpleRuleEngine } from '@x-apaas/x-lib-rule-engine';
```

## 三、Rule（规则）

规则数据模型，描述一条完整的业务规则。

**引入方式：**
```js
import { Rule } from '@x-apaas/x-lib-rule-engine';
```

**属性：**

| 属性 | 类型 | 说明 |
|------|------|------|
| `elements` | `Array<RuleElement>` | 规则元素列表 |

---

## 四、RuleElement（规则元素）

规则的最小组成单元，表示规则中的一个节点。

**引入方式：**
```js
import { RuleElement } from '@x-apaas/x-lib-rule-engine';
```

**属性：**

| 属性 | 类型 | 说明 |
|------|------|------|
| `ruleType` | `RuleType \| String` | 规则元素类型 |
| `displayName` | `String` | 显示名称（函数/字段/运算符的展示名） |
| `funcName` | `String` | 函数名/字段名/运算符名 |
| `value` | `String \| Number` | 静态值或表单字段UUID |
| `paramType` | `'number' \| 'string' \| 'bool' \| 'pepselect' \| 'orgselect' \| 'roleselect' \| 'array'` | 参数类型 |
| `validExpr` | `any` | 表达式验证专用默认值 |
| `properties` | `Map<String, Object>` | 附加字段 |

## 五、RuleType（规则类型枚举）

**引入方式：**
```js
import { RuleType } from '@x-apaas/x-lib-rule-engine';
```

| 枚举值 | 说明 |
|--------|------|
| `FUNCTION` | 函数 |
| `STATIC` | 静态值 |
| `EXPRESS_FUNCTION` | 表达式函数 |
| `COMPONENT_VALUE` | 组件值 |
| `EXPRESS_FIELD` | 表达式字段 |
| `OPERATION` | 运算符 |
| `SEPARATOR` | 分隔符 |
| `EMPTY` | 空值 |
| `TABLE_ROW_SEQUENCE_NUMBER` | 表格行序号 |
| `SON_TABLE_CURRENT_LINE` | 子表当前行 |

## 六、RuleExecutor（规则执行器）

负责规则的执行和表达式验证。

**引入方式：**
```js
import { RuleExecutor } from '@x-apaas/x-lib-rule-engine';
```

**构造函数：**
```js
new RuleExecutor(ruleEngine, executorUuid?)
```
| 参数 | 类型 | 说明 |
|------|------|------|
| `ruleEngine` | `RuleEngine` | 规则引擎实例 |
| `executorUuid?` | `String` | 执行器唯一标识 |

**实例方法：**

| 方法 | 参数 | 返回值 | 说明 |
|------|------|--------|------|
| `executeRule(rule)` | `rule: Rule` | `any` | 执行规则 |
| `executeRuleWithContext(rule, ruleContext)` | `rule: Rule`<br>`ruleContext: RuleRuntimeContext` | `any` | 在指定上下文中执行规则 |

**静态方法：**

| 方法 | 参数 | 返回值 | 说明 |
|------|------|--------|------|
| `validateRuleExpr(ruleExpr, ruleEngine?)` | `ruleExpr: String` - 规则表达式<br>`ruleEngine?: RuleEngine` | `Boolean` | 验证规则表达式是否合法 |

---

## 七、RuleParser（规则解析器）

负责规则的解析和转换。

**引入方式：**
```js
import { RuleParser } from '@x-apaas/x-lib-rule-engine';
```

**静态方法：**

| 方法 | 参数 | 返回值 | 说明 |
|------|------|--------|------|
| `parseRuleToExpr(rule)` | `rule: Rule` | `String` | 将规则对象解析为表达式字符串 |
| `convertRuleToValidExpr(rule)` | `rule: Rule` | `String` | 将规则转换为可验证的表达式字符串 |

## 九、RuleRuntimeContext（规则运行上下文）

规则执行的上下文环境，管理绑定的上下文方法。

**引入方式：**
```js
import { RuleRuntimeContext } from '@x-apaas/x-lib-rule-engine';
```

**构造函数：**
```js
new RuleRuntimeContext(validMock, ruleEngine)
```
| 参数 | 类型 | 说明 |
|------|------|------|
| `validMock` | `Boolean` | 是否为验证模拟模式 |
| `ruleEngine` | `RuleEngine` | 规则引擎实例 |

**实例方法：**

| 方法 | 参数 | 返回值 | 说明 |
|------|------|--------|------|
| `unbindContextMethods()` | 无 | `void` | 解绑上下文方法 |

**属性：**

| 属性 | 类型 | 说明 |
|------|------|------|
| `validMock` | `Boolean` | 是否为验证模拟模式 |
| `ruleEngine` | `RuleEngine` | 关联的规则引擎实例 |

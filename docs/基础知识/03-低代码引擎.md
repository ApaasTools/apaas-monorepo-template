# 低代码引擎 API 文档

> 包名：`@x-apaas/x-dcloud-low-code-engine`  
> 入口：`dist/index.d.ts`

## 概述

低代码引擎提供脚本执行、样式执行和组件扩展能力，允许用户通过低代码脚本自定义业务逻辑和界面行为。

---

## 一、LowCodeEngine（低代码引擎）

低代码引擎主类，采用单例模式，提供脚本执行和上下文管理能力。

**引入方式：**
```js
import { LowCodeEngine } from '@x-apaas/x-dcloud-low-code-engine';
```

### 静态方法

| 方法 | 参数 | 返回值 | 说明 |
|------|------|--------|------|
| `getInstance()` | 无 | `LowCodeEngine` | 获取低代码引擎单例实例 |

### 实例方法

| 方法 | 参数 | 返回值 | 说明 |
|------|------|--------|------|
| `registerContextProperty(key, value)` | `key: String` - 属性键名<br>`value: any` - 属性值 | `void` | 注册上下文属性 |
| `unRegisterContextProperty(key)` | `key: String` - 属性键名 | `this` | 注销上下文属性（支持链式调用） |
| `registerContextMethod(key, value)` | `key: String` - 方法键名<br>`value: Function` - 方法函数 | `void` | 注册上下文方法 |
| `unRegisterContextMethod(key)` | `key: String` - 方法键名 | `this` | 注销上下文方法（支持链式调用） |
| `executeLowCodeScript(lowCodeScriptStr, context?, executorUuid?)` | `lowCodeScriptStr: any` - 低代码脚本字符串<br>`context?: Object` - 执行上下文<br>`executorUuid?: String` - 执行器唯一标识 | `any` | 执行低代码脚本 |
| `executeLowCodeStyle(lowCodeStyleStr, executorUuid?)` | `lowCodeStyleStr: any` - 低代码样式字符串<br>`executorUuid?: String` - 执行器唯一标识 | `void` | 执行低代码样式 |
| `extendComponent(Vue, options, parent, executorUuid?)` | `Vue: any` - Vue 构造函数<br>`options: any` - 组件选项<br>`parent: any` - 父组件<br>`executorUuid?: String` - 执行器唯一标识 | `any` | 扩展组件 |
| `extendModalComponent(platform, Vue, options, parent)` | `platform: String` - 平台类型<br>`Vue: any` - Vue 构造函数<br>`options: any` - 组件选项<br>`parent: any` - 父组件 | `any` | 扩展弹窗组件 |

**使用示例：**
```js
const engine = LowCodeEngine.getInstance();

// 注册上下文属性
engine.registerContextProperty('currentUser', { name: '张三' });

// 注册上下文方法
engine.registerContextMethod('showMessage', (msg) => alert(msg));

// 执行低代码脚本
const result = engine.executeLowCodeScript('return currentUser.name');

// 执行低代码样式
engine.executeLowCodeStyle('.custom-class { color: red; }');
```

## 二、LowCodeExecutor（低代码执行器）

负责低代码脚本和样式的具体执行。

**引入方式：**
```js
import { LowCodeExecutor } from '@x-apaas/x-dcloud-low-code-engine';
```

**实例方法：**

| 方法 | 参数 | 返回值 | 说明 |
|------|------|--------|------|
| `executeLowCodeScript(lowCodeScriptStr, context?)` | `lowCodeScriptStr: String` - 脚本字符串<br>`context?: Object` - 执行上下文 | `any` | 执行低代码脚本 |
| `executeLowCodeStyle(lowCodeStyleStr)` | `lowCodeStyleStr: any` - 样式字符串 | `void` | 执行低代码样式 |
| `extendVueComponent(Vue, options, parent)` | `Vue: any` - Vue 构造函数<br>`options: any` - 组件选项<br>`parent: any` - 父组件 | `any` | 扩展 Vue 组件 |
| `extendHtmlComponent(selector, html)` | `selector: any` - CSS 选择器<br>`html: String` - HTML 内容 | `void` | 扩展 HTML 组件 |

**静态方法：**

| 方法 | 参数 | 返回值 | 说明 |
|------|------|--------|------|
| `validateLowCodeScript(lowCodeScriptStr, context?)` | `lowCodeScriptStr: String` - 脚本字符串<br>`context?: Object` - 执行上下文 | `{ result: Boolean, msg?: String }` | 验证低代码脚本是否合法 |
| `validateLowCodeStyle(lowCodeStyleStr)` | `lowCodeStyleStr: String` - 样式字符串 | `{ result: Boolean, msg?: String }` | 验证低代码样式是否合法 |

**使用示例：**
```js
const executor = new LowCodeExecutor();

// 验证脚本
const validation = LowCodeExecutor.validateLowCodeScript('return 1 + 1');
if (validation.result) {
  const result = executor.executeLowCodeScript('return 1 + 1');
}

// 验证样式
const styleValidation = LowCodeExecutor.validateLowCodeStyle('.red { color: red; }');
```

## 四、LowCodeRunTime（低代码运行时）

封装单次低代码脚本/样式执行的运行时实例。

**引入方式：**
```js
import LowCodeRunTime from '@x-apaas/x-dcloud-low-code-engine/dist/LowCodeRunTime';
```

**构造函数：**
```js
new LowCodeRunTime(lowCodeStr, lowCodeExecutor, context?)
```
| 参数 | 类型 | 说明 |
|------|------|------|
| `lowCodeStr` | `String` | 低代码脚本字符串 |
| `lowCodeExecutor` | `LowCodeExecutor` | 低代码执行器 |
| `context?` | `Object` | 执行上下文 |

**实例方法：**

| 方法 | 参数 | 返回值 | 说明 |
|------|------|--------|------|
| `executeLowCodeScript()` | 无 | `any` | 执行低代码脚本 |
| `executeLowCodeStyle()` | 无 | `void` | 执行低代码样式 |

**属性：**

| 属性 | 类型 | 说明 |
|------|------|------|
| `uuid` | `String` | 运行时唯一标识 |
| `lowCodeStr` | `String` | 低代码脚本字符串 |
| `lowCodeContext` | `LowCodeRuntimeContext` | 运行上下文 |
| `lowCodeExecutor` | `LowCodeExecutor` | 低代码执行器 |

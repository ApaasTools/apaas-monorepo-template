# 业务对象与事件 API 文档

> 业务对象包：`@x-apaas/x-dcloud-business-object`  
> 业务事件包：`@x-apaas/x-dcloud-business-event`

## 概述

业务对象与事件模块是 APAAS 平台的数据层核心，业务对象提供数据实体的工作区管理，业务事件提供事件触发、规则适配和组件联动能力。

---

## 一、业务对象 (@x-apaas/x-dcloud-business-object)

### 导出模块

```js
import BusinessObject from '@x-apaas/x-dcloud-business-object';

const { install, BusinessObjectWorkspace } = BusinessObject;
```

### BusinessObjectWorkspace（业务对象工作区）

业务对象工作区 Vue 组件，提供业务对象数据的完整管理界面。

**使用方式：**
```html
<BusinessObjectWorkspace 
  ref="workspace" 
  :bo-code="boCode" 
  :form-config="formConfig"
  @on-save="handleSave"
/>
```

**Props：**

| 属性 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `boCode` | `String` | - | 业务对象编码 |
| `formConfig` | `Object` | - | 表单配置 |

**插件安装：**
```js
import BusinessObject from '@x-apaas/x-dcloud-business-object';
Vue.use(BusinessObject);
```

## 二、业务事件 (@x-apaas/x-dcloud-business-event)

### 导出模块

```js
import BsEventTriggerEngine from '@x-apaas/x-dcloud-business-event/lib/bs-event-trigger';
import RuleComponentEngine from '@x-apaas/x-dcloud-business-event/lib/rule-component-engine';
import RuleModalUtil from '@x-apaas/x-dcloud-business-event/lib/rule-modal-util';
```

### BsEventTriggerEngine（业务事件触发引擎）

业务事件触发引擎，负责在数据操作时触发相应的业务事件和规则。

**引入方式：**
```js
import BsEventTriggerEngine from '@x-apaas/x-dcloud-business-event/lib/bs-event-trigger';
```

**核心能力：**
- 监听业务对象的数据变更事件
- 触发关联的业务规则
- 管理事件与规则的映射关系

**主要方法：**

| 方法 | 参数 | 返回值 | 说明 |
|------|------|--------|------|
| `triggerEvent(eventName, context)` | `eventName: String` - 事件名<br>`context: Object` - 事件上下文 | `void` | 触发业务事件 |
| `registerEvent(eventName, handler)` | `eventName: String` - 事件名<br>`handler: Function` - 事件处理函数 | `void` | 注册事件处理器 |
| `unRegisterEvent(eventName)` | `eventName: String` - 事件名 | `void` | 注销事件处理器 |

**使用示例：**
```js
// 创建事件触发引擎
const triggerEngine = new BsEventTriggerEngine();

// 触发业务事件
triggerEngine.triggerEvent('onFieldValueChange', {
  fieldName: 'amount',
  oldValue: 100,
  newValue: 200,
  formData: currentFormData
});
```

### RuleComponentEngine（规则组件引擎）

规则组件引擎，负责将业务规则绑定到 UI 组件，实现组件间的联动。

**引入方式：**
```js
import RuleComponentEngine from '@x-apaas/x-dcloud-business-event/lib/rule-component-engine';
```

**核心能力：**
- 将规则绑定到组件
- 当规则执行结果变化时更新组件状态
- 管理组件的显隐、只读、必填等联动逻辑

**主要方法：**

| 方法 | 参数 | 返回值 | 说明 |
|------|------|--------|------|
| `bindRuleToComponent(rule, componentRef)` | `rule: Rule` - 规则对象<br>`componentRef: Vue` - 组件引用 | `void` | 绑定规则到组件 |
| `unbindRule(ruleId)` | `ruleId: String` - 规则ID | `void` | 解绑规则 |
| `executeComponentRules(componentUuid)` | `componentUuid: String` - 组件UUID | `void` | 执行指定组件的所有规则 |

---

### RuleModalUtil（规则弹窗工具）

规则弹窗工具，提供规则编辑器的弹窗交互能力。

**引入方式：**
```js
import RuleModalUtil from '@x-apaas/x-dcloud-business-event/lib/rule-modal-util';
```

**核心能力：**
- 打开规则编辑弹窗
- 获取规则编辑结果
- 验证规则配置

**主要方法：**

| 方法 | 参数 | 返回值 | 说明 |
|------|------|--------|------|
| `openRuleModal(options)` | `options: Object` - 弹窗配置 | `Promise<Rule>` | 打开规则编辑弹窗，返回编辑结果 |
| `validateRule(rule)` | `rule: Rule` - 规则对象 | `Boolean` | 验证规则是否合法 |

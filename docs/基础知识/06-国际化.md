# 国际化 API 文档

> 包名：`@x-apaas/x-apaas-frontend-i18n`  
> 入口：`index.js`、`util/index.js`

## 概述

国际化模块提供多语言支持和时区处理能力，支持 10 种语言，集成 vue-i18n，提供时区转换和日期处理工具。

---

## 一、语言常量

### ZH_CN / EN

预定义的语言包。

**引入方式：**
```js
import { ZH_CN, EN } from '@x-apaas/x-apaas-frontend-i18n';
```

### LANG_TYPE_LIST

支持的语言类型列表。

**引入方式：**
```js
import { LANG_TYPE_LIST } from '@x-apaas/x-apaas-frontend-i18n';
```

**结构：**
```js
// 语言类型列表，包含所有支持的语言配置
LANG_TYPE_LIST: Array<{
  label: String,   // 语言显示名
  value: String    // 语言代码
}>
```

### ENV_LANG_MAP

环境语言映射，将环境标识映射为语言代码。

**引入方式：**
```js
import { ENV_LANG_MAP } from '@x-apaas/x-apaas-frontend-i18n';
```

## 二、i18n 注册与管理

### registerVueI18N(options)

注册 Vue I18N 实例到 Vue 应用。

**引入方式：**
```js
import { registerVueI18N } from '@x-apaas/x-apaas-frontend-i18n';
```

**参数：**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `options` | `Object` | 是 | Vue I18N 配置项 |
| `options.locale` | `String` | 否 | 默认语言 |
| `options.fallbackLocale` | `String` | 否 | 回退语言 |
| `options.messages` | `Object` | 否 | 语言包消息 |

**返回值：** `VueI18n` 实例

**使用示例：**
```js
const i18n = registerVueI18N({
  locale: 'zh_CN',
  fallbackLocale: 'en',
  messages: { zh_CN: ZH_CN, en: EN }
});

new Vue({ i18n }).$mount('#app');
```

### getVueI18N()

获取已注册的 Vue I18N 实例。

**引入方式：**
```js
import { getVueI18N } from '@x-apaas/x-apaas-frontend-i18n';
```

**参数：** 无

**返回值：** `VueI18n` 实例

**使用示例：**
```js
const i18n = getVueI18N();
const message = i18n.t('key.path');
```

### mergeLocaleMessage(locale, messages)

合并指定语言的消息包。

**引入方式：**
```js
import { mergeLocaleMessage } from '@x-apaas/x-apaas-frontend-i18n';
```

**参数：**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `locale` | `String` | 是 | 语言代码 |
| `messages` | `Object` | 是 | 要合并的消息对象 |

**返回值：** `void`

**使用示例：**
```js
mergeLocaleMessage('zh_CN', {
  customModule: {
    title: '自定义标题'
  }
});
```

## 三、时区工具

### TIMEZONE_LIST

时区列表，包含所有支持的时区配置。

**引入方式：**
```js
import { TIMEZONE_LIST } from '@x-apaas/x-apaas-frontend-i18n/util';
```

### XDate

增强的日期处理类，基于 dayjs 封装，支持时区转换。

**引入方式：**
```js
import { XDate } from '@x-apaas/x-apaas-frontend-i18n/util';
```

**主要方法：**

| 方法 | 参数 | 返回值 | 说明 |
|------|------|--------|------|
| `constructor(date?)` | `date?: String \| Date` | `XDate` | 创建 XDate 实例 |
| `format(formatStr)` | `formatStr: String` | `String` | 格式化日期 |
| `timezone(tz)` | `tz: String` | `XDate` | 设置时区 |
| `valueOf()` | 无 | `Number` | 获取时间戳 |

### getXdapTimezone()

获取 XDAP 平台配置的时区。

**引入方式：**
```js
import { getXdapTimezone } from '@x-apaas/x-apaas-frontend-i18n/util';
```

**参数：** 无

**返回值：** `String` - 时区标识

### getLocaleTimezoneWithUTC()

获取本地时区的 UTC 表示。

**引入方式：**
```js
import { getLocaleTimezoneWithUTC } from '@x-apaas/x-apaas-frontend-i18n/util';
```

**参数：** 无

**返回值：** `String` - UTC 时区字符串（如 `UTC+8`）

### getDateByUTCTimezone(date, timezone)

根据 UTC 时区获取日期。

**引入方式：**
```js
import { getDateByUTCTimezone } from '@x-apaas/x-apaas-frontend-i18n/util';
```

**参数：**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `date` | `String \| Date` | 是 | 日期 |
| `timezone` | `String` | 是 | UTC 时区 |

**返回值：** `Date`

### setTimezoneDate(date, timezone)

设置日期的时区。

**引入方式：**
```js
import { setTimezoneDate } from '@x-apaas/x-apaas-frontend-i18n/util';
```

**参数：**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `date` | `String \| Date` | 是 | 日期 |
| `timezone` | `String` | 是 | 时区 |

**返回值：** `Date`

### getTimezoneDate(date, timezone)

获取指定时区的日期表示。

**引入方式：**
```js
import { getTimezoneDate } from '@x-apaas/x-apaas-frontend-i18n/util';
```

**参数：**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `date` | `String \| Date` | 是 | 日期 |
| `timezone` | `String` | 是 | 时区 |

**返回值：** `Date`

### initTimezoneConfig(config)

初始化时区配置。

**引入方式：**
```js
import { initTimezoneConfig } from '@x-apaas/x-apaas-frontend-i18n/util';
```

**参数：**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `config` | `Object` | 是 | 时区配置 |
| `config.timezone` | `String` | 是 | 默认时区 |

**返回值：** `void`

### getTimezoneInterval(timezone1, timezone2)

获取两个时区之间的时间差。

**引入方式：**
```js
import { getTimezoneInterval } from '@x-apaas/x-apaas-frontend-i18n/util';
```

**参数：**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `timezone1` | `String` | 是 | 时区1 |
| `timezone2` | `String` | 是 | 时区2 |

**返回值：** `Number` - 时区差（小时）

### TimezoneMixin

时区混入，注入到 Vue 组件中提供时区操作能力。

**引入方式：**
```js
import { TimezoneMixin } from '@x-apaas/x-apaas-frontend-i18n/util';
```

**使用方式：**
```js
export default {
  mixins: [TimezoneMixin],
  methods: {
    handleDate() {
      const tz = this.$getTimezone();
      const formatted = this.$formatTzDate(new Date(), 'YYYY-MM-DD');
    }
  }
}
```

### initApaasDate()

初始化 APAAS 日期配置。

**引入方式：**
```js
import { initApaasDate } from '@x-apaas/x-apaas-frontend-i18n/util';
```

**参数：** 无

**返回值：** `void`

### apaasDate

APAAS 日期实例，提供全局日期操作。

**引入方式：**
```js
import { apaasDate } from '@x-apaas/x-apaas-frontend-i18n/util';
```

## 四、Vue 实例方法

注册 i18n 后，Vue 组件实例可使用以下方法：

| 方法 | 参数 | 返回值 | 说明 |
|------|------|--------|------|
| `this.$t(key, ...values)` | `key: String` - 翻译键<br>`values: any[]` - 插值参数 | `String` | 翻译文本 |
| `this.$tc(key, choice, ...values)` | `key: String` - 翻译键<br>`choice: Number` - 选择项<br>`values: any[]` - 插值参数 | `String` | 翻译复数文本 |
| `this.$te(key, locale?)` | `key: String` - 翻译键<br>`locale?: String` - 语言 | `Boolean` | 检查翻译键是否存在 |
| `this.$d(value, ...args)` | `value: Date` - 日期<br>`args` - 格式化参数 | `String` | 格式化日期 |
| `this.$n(value, ...args)` | `value: Number` - 数字<br>`args` - 格式化参数 | `String` | 格式化数字 |

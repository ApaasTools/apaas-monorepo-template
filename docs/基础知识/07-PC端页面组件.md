# PC 端页面组件 API 文档

> 包名：`@x-apaas/x-dcloud-page-web`  
> 入口：`lib/es/index.js`  
> 版本：3.2.20.11-bugfix.115

## 概述

PC 端页面组件库，提供表单设计器、表单查看/编辑、列表、数据选择器等完整的低代码页面组件，是 APAAS 平台 PC 端页面的核心渲染层。

---

## 一、表单设计类组件

### XFormDesign

表单设计器组件，提供拖拽式的表单设计能力。

**使用方式：**
```html
<XFormDesign 
  ref="formDesign"
  :form-config="formConfig"
  :bo-code="boCode"
  @on-save="handleSave"
/>
```

**Props：**

| 属性 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `formConfig` | `Object` | - | 表单配置 |
| `boCode` | `String` | - | 业务对象编码 |

### XFormDesignCombine

组合表单设计器组件，支持多表单组合设计。

### XPublicFormSetting

公共表单设置组件，配置公共表单的访问权限和展示。

### XPublicFormView

公共表单查看组件，渲染公共表单的只读视图。

---

## 二、表单查看/编辑类组件

### XFormReadDrawer

表单只读抽屉组件，在抽屉中以只读模式展示表单数据。

**使用方式：**
```html
<XFormReadDrawer
  :visible="drawerVisible"
  :form-data="formData"
  :form-config="formConfig"
  @on-close="handleClose"
/>
```

**Props：**

| 属性 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `visible` | `Boolean` | `false` | 是否显示抽屉 |
| `formData` | `Object` | - | 表单数据 |
| `formConfig` | `Object` | - | 表单配置 |

**Events：**

| 事件名 | 参数 | 说明 |
|--------|------|------|
| `on-close` | 无 | 关闭抽屉时触发 |

### XFormCombineReadDrawer

组合表单只读抽屉组件，支持多表单组合只读展示。

### XFormEditModal

表单编辑弹窗组件，在弹窗中提供表单编辑能力。

**使用方式：**
```html
<XFormEditModal
  :visible="modalVisible"
  :form-data="formData"
  :form-config="formConfig"
  :bo-code="boCode"
  @on-save="handleSave"
  @on-close="handleClose"
/>
```

**Props：**

| 属性 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `visible` | `Boolean` | `false` | 是否显示弹窗 |
| `formData` | `Object` | - | 表单数据 |
| `formConfig` | `Object` | - | 表单配置 |
| `boCode` | `String` | - | 业务对象编码 |

**Events：**

| 事件名 | 参数 | 说明 |
|--------|------|------|
| `on-save` | `formData: Object` | 保存时触发 |
| `on-close` | 无 | 关闭弹窗时触发 |

### XFormEditDebugDrawer

表单编辑调试抽屉组件，用于开发调试表单逻辑。

## 三、表单字段类组件

### XProxyFormItem

表单字段代理组件，作为表单中每个字段的包装器，处理校验、显隐、只读等逻辑。

**Props：**

| 属性 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `showRequired` | `Boolean` | - | 是否显示必填标记 |
| `validatorRules` | `Array` | - | 校验规则列表 |
| `validateKey` | `String` | - | 校验键名 |
| `label` | `String` | - | 字段标签 |
| `processTitle` | `Boolean` | - | 是否处理标题 |
| `validateInfo` | `Object` | - | 校验信息 |
| `disabled` | `Boolean` | - | 是否禁用 |
| `mobileFormSettings` | `Object` | `{}` | 移动端表单设置 |
| `widget` | `Object` | `{}` | 组件配置 |

### XHelpTooltip

帮助提示组件，显示字段帮助信息。

### XBadge

徽标组件，显示状态标记。

### XLovInput

LOV（值列表）输入组件，提供下拉选择和搜索能力。

**Props：**

| 属性 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `value` | `String \| Number` | - | 当前值 |
| `lovCode` | `String` | - | LOV 编码 |

**Events：**

| 事件名 | 参数 | 说明 |
|--------|------|------|
| `change` | `value: any` | 值变更时触发 |

### XSelectPersonInput

人员选择输入组件，提供人员选择器。

### XSelectPersonDropdown

人员选择下拉组件，提供人员下拉选择。

### XI18nInput

国际化输入组件，支持多语言输入。

### XI18nPopover

国际化弹出框组件，展示多语言信息。

## 四、流程相关组件

### XProcessStatus

流程状态组件，显示流程审批状态。

### XProcessStatusCard

流程状态卡片组件，以卡片形式展示流程状态信息。

---

## 五、数据展示类组件

### XHttpBlockTable

HTTP 数据块表格组件，通过 HTTP 请求加载并展示表格数据。

**Props：**

| 属性 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `url` | `String` | - | 数据请求地址 |
| `params` | `Object` | - | 请求参数 |
| `columns` | `Array` | - | 列配置 |

### XTableStatisticalCell

表格统计单元格组件，显示列的汇总统计信息。

### XSonTableLogsModal

子表操作日志弹窗组件，展示子表的变更历史。

### XDateFormatModal

日期格式设置弹窗组件，配置日期展示格式。

---

## 六、文件上传类组件

### FormUploadModal

表单文件上传弹窗组件，提供文件上传功能。

**使用方式：**
```html
<FormUploadModal
  :visible="uploadVisible"
  :file-list="fileList"
  @on-upload="handleUpload"
  @on-close="handleClose"
/>
```

### UploadFileTable

文件上传列表组件，展示已上传文件列表。

---

## 七、日期格式化插件

### XDateFormatPlugin / DateFormatPlugin

日期格式化 Vue 插件，提供全局日期格式化能力。

**使用方式：**
```js
Vue.use(XDateFormatPlugin);
```

---

## 八、XFormExtend（表单扩展）

表单扩展模块，提供表单的扩展能力。

**引入方式：**
```js
import { XFormExtend } from '@x-apaas/x-dcloud-page-web';
```

---

## 九、XFormWidget

表单组件集，包含所有表单字段的渲染组件（通过 `Object.keys(XFormWidget)` 遍历获取）。

---

## 十、AssetLoader

资源加载器，自动加载 SVG 图标资源。

**引入方式：**
```js
import { AssetLoader } from '@x-apaas/x-dcloud-page-web';
```

---

## 插件安装

```js
import PageWeb from '@x-apaas/x-dcloud-page-web';
Vue.use(PageWeb);
```

安装后注册所有组件为全局组件，并启用 VueLazyload 和 DateFormatPlugin。

# 移动端页面组件 API 文档

> 包名：`@x-apaas/x-dcloud-page-mobile`  
> 入口：`lib/es/index.js`

## 概述

移动端页面组件库，提供移动端表单渲染、列表展示、组件扩展等能力，依赖页面引擎和低代码引擎实现移动端低代码页面的渲染与交互。

---

## 核心依赖

- `@x-apaas/x-dcloud-low-code-engine` — 低代码引擎
- `@x-apaas/x-dcloud-page-engine` — 页面引擎（AbilityControl, WidgetControl, NetworkControl, ExtendControl, FormLogicMixin, FormEngine）
- `x-extension` — 扩展引擎（ExtensionEngine, ExtensionMixin）
- `@x-apaas/x-apaas-frontend-i18n` — 国际化
- `vuex` — 状态管理

---

## 一、XProxyFormItem（移动端表单字段代理）

移动端表单字段代理组件，处理字段校验、显隐、只读等逻辑。

**Props：**

| 属性 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `showRequired` | `Boolean` | - | 是否显示必填标记 |
| `validatorRules` | `Array` | - | 校验规则列表 |
| `validateKey` | `String` | - | 校验键名 |
| `label` | `String` | - | 字段标签 |
| `processTitle` | `Boolean` | - | 是否处理标题 |
| `validateInfo` | `Object` | - | 校验信息 |
| `disabled` | `Boolean` | - | 是否禁用 |
| `mobileFormSettings` | `Object` | `{}` | 移动端表单设置 |
| `widget` | `Object` | `{}` | 组件配置 |

---

## 二、移动端表单组件

移动端提供与 PC 端对应的表单渲染组件，针对移动端交互优化：

- 表单只读视图
- 表单编辑视图
- 子表操作
- 人员选择
- 日期选择
- 下拉选择
- 文件上传/预览
- 位置选择
- 数据选择器

---

## 三、移动端列表组件

- 列表数据展示
- 下拉刷新
- 上拉加载更多
- 列表筛选
- 列表搜索

---

## 四、扩展机制

移动端组件同样支持通过 `ExtensionEngine` 和 `ExtensionMixin` 进行扩展：

```js
import { ExtensionEngine, ExtensionMixin } from 'x-extension';
```

---

## 插件安装

```js
import PageMobile from '@x-apaas/x-dcloud-page-mobile';
Vue.use(PageMobile);
```

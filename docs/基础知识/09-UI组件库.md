# UI 组件库 API 文档

包含以下四个 UI 组件包：
- `@x-ui/x-dcloud-ui` — PC 端 UI 组件库
- `@x-ui/x-dcloud-mui` — 移动端 UI 组件库
- `@x-ui/x-lib-ui` — 基础 UI 组件库
- `@x-ui/x-guard` — 守卫监控组件库

---

## 一、PC 端 UI 组件库 (@x-ui/x-dcloud-ui)

> 入口：`lib/index.js`

基于 Element UI 扩展的 PC 端业务 UI 组件库，集成 quill 富文本、wangEditor 富文本、axios 等依赖。

### 核心依赖

- `quill` + `quill-mention` — Quill 富文本编辑器
- `@x-apaas/x-wangeditor` — wangEditor 富文本编辑器
- `vue` + `lodash` + `axios`

### 组件列表

| 组件名 | 说明 |
|--------|------|
| `XDate` | 日期选择器组件，增强 Element UI 日期选择 |

**XDate Props：**

| 属性 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `clearable` | `Boolean` | `true` | 是否可清空 |
| `disabled` | `Boolean` | `false` | 是否禁用 |
| `value` | `String \| Date \| Array` | `''` | 绑定值 |
| `appendToBody` | `Boolean` | `false` | 是否插入到 body |
| `flipBehavior` | `Array` | `['bottom','top','left','right']` | 翻转行为 |

**Events：**

| 事件名 | 参数 | 说明 |
|--------|------|------|
| `change` | `value: String \| Date \| Array` | 值变更时触发 |

### 其他组件

组件库包含大量基于 Element UI 扩展的业务组件，涵盖：
- 增强型输入组件
- 增强型选择组件
- 增强型表格组件
- 富文本编辑器组件（Quill / wangEditor）
- 文件上传组件
- 布局容器组件

### 插件安装

```js
import XDcloudUI from '@x-ui/x-dcloud-ui';
Vue.use(XDcloudUI);
```

## 二、移动端 UI 组件库 (@x-ui/x-dcloud-mui)

> 入口：`lib/index.js`

基于 vuedraggable、sortablejs、axios 等的移动端业务 UI 组件库。

### 核心依赖

- `sortablejs` + `vuedraggable` — 拖拽排序
- `vue` + `lodash` + `axios`
- `x-lib-mock` — Mock 数据

### 组件列表

| 组件名 | 说明 |
|--------|------|
| `XSvgIcon` | SVG 图标组件 |

**XSvgIcon Props：**

| 属性 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `name` | `String` | (必填) | 图标名称 |
| `width` | `Number` | `24` | 图标宽度 |
| `height` | `Number` | `24` | 图标高度 |

### 插件安装

```js
import XDcloudMui from '@x-ui/x-dcloud-mui';
Vue.use(XDcloudMui);
```

## 四、守卫监控组件库 (@x-ui/x-guard)

> 入口：`lib/index.js`

基于 ECharts 的应用监控仪表盘组件库，提供系统运行状态的实时可视化。

### 组件列表

| 组件名 | 说明 |
|--------|------|
| `GAppChart` | 应用状态图表，展示应用运行概况 |
| `GCpuChart` | CPU 使用率图表，实时监控 CPU 占用 |
| `GMemoryChart` | 内存使用图表，实时监控内存占用 |
| `GThreadChart` | 线程状态图表，监控线程运行情况 |
| `GWaterChart` | 水位图，展示资源使用水位线 |
| `GIssuesCount` | 问题统计组件，展示问题数量汇总 |
| `GIssuesDetail` | 问题详情组件，展示问题详细信息 |
| `GIssuesList` | 问题列表组件，展示问题列表 |

### 使用示例

```html
<template>
  <div class="dashboard">
    <GAppChart :app-data="appData" />
    <GCpuChart :cpu-data="cpuData" />
    <GMemoryChart :memory-data="memoryData" />
    <GIssuesCount :count-data="countData" />
  </div>
</template>
```

### 插件安装

```js
import XGuard from '@x-ui/x-guard';
Vue.use(XGuard);
```

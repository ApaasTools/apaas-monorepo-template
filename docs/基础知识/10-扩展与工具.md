# 扩展与工具 API 文档

包含以下模块：
- `x-extension` — 扩展引擎
- `@x-apaas/x-wangeditor` — 富文本编辑器

## 一、扩展引擎 (x-extension)

> 包名：`x-extension`  
> 入口：`lib/index.js`

扩展引擎提供组件扩展和混入能力，允许在运行时动态扩展 APAAS 平台的功能。

### ExtensionEngine（扩展引擎）

扩展引擎核心类，管理扩展点的注册和执行。

**引入方式：**
```js
import { ExtensionEngine } from 'x-extension';
```

**主要方法：**

| 方法 | 参数 | 返回值 | 说明 |
|------|------|--------|------|
| `registerExtension(extension)` | `extension: Object` - 扩展配置 | `void` | 注册扩展 |
| `unRegisterExtension(extensionId)` | `extensionId: String` - 扩展ID | `void` | 注销扩展 |
| `getExtensions(point?)` | `point?: String` - 扩展点 | `Array` | 获取扩展列表 |
| `executeExtension(point, context)` | `point: String` - 扩展点<br>`context: Object` - 执行上下文 | `any` | 执行指定扩展点的所有扩展 |

**使用示例：**
```js
const engine = new ExtensionEngine();

// 注册扩展
engine.registerExtension({
  id: 'custom-button',
  point: 'form-toolbar',
  component: CustomButtonComponent,
  props: { label: '自定义按钮' }
});

// 获取指定扩展点的所有扩展
const extensions = engine.getExtensions('form-toolbar');
```

---

### ExtensionMixin（扩展混入）

Vue 混入，注入扩展能力到 Vue 组件中。

**引入方式：**
```js
import { ExtensionMixin } from 'x-extension';
```

**使用方式：**
```js
export default {
  mixins: [ExtensionMixin],
  // 组件可通过 this.$extension 访问扩展引擎
}
```

---

### 插件安装

```js
import XExtension from 'x-extension';
Vue.use(XExtension);
```

## 二、富文本编辑器 (@x-apaas/x-wangeditor)

> 包名：`@x-apaas/x-wangeditor`  
> 版本：4.4.8  
> 入口：`dist/wangEditor.js` / `dist/wangEditor.min.js`  
> 类型：`dist/wangEditor.d.ts`  
> 官网：http://www.wangeditor.com/

基于 wangEditor 4.x 的富文本编辑器封装，提供轻量级的 Web 富文本编辑能力。

### 核心 API

**引入方式：**
```js
import E from '@x-apaas/x-wangeditor';
```

### 构造函数

```js
const editor = new E(selector);
```

| 参数 | 类型 | 说明 |
|------|------|------|
| `selector` | `String \| HTMLElement` | 编辑器容器的 CSS 选择器或 DOM 元素 |

### 实例方法

#### 配置类

| 方法 | 参数 | 返回值 | 说明 |
|------|------|--------|------|
| `config.zIndex(number)` | `number: Number` | `void` | 设置编辑器 z-index |
| `config.placeholder(placeholder)` | `placeholder: String` | `void` | 设置占位文本 |
| `config.focus(focus)` | `focus: Boolean` | `void` | 是否自动聚焦 |
| `config.onchange(fn)` | `fn: Function` | `void` | 内容变更回调 |
| `config.onfocus(fn)` | `fn: Function` | `void` | 获得焦点回调 |
| `config.onblur(fn)` | `fn: Function` | `void` | 失去焦点回调 |

#### 内容操作类

| 方法 | 参数 | 返回值 | 说明 |
|------|------|--------|------|
| `create()` | 无 | `void` | 创建编辑器实例 |
| `destroy()` | 无 | `void` | 销毁编辑器实例 |
| `html()` | 无 | `String` | 获取 HTML 内容 |
| `text()` | 无 | `String` | 获取纯文本内容 |
| `html(content)` | `content: String` | `void` | 设置 HTML 内容 |
| `appendHtml(html)` | `html: String` | `void` | 追加 HTML 内容 |
| `clear()` | 无 | `void` | 清空编辑器内容 |

#### 禁用/启用

| 方法 | 参数 | 返回值 | 说明 |
|------|------|--------|------|
| `disable()` | 无 | `void` | 禁用编辑器 |
| `enable()` | 无 | `void` | 启用编辑器 |

#### 菜单配置

| 方法 | 参数 | 返回值 | 说明 |
|------|------|--------|------|
| `config.menus(menus)` | `menus: Array<String>` | `void` | 自定义菜单列表 |
| `config.excludeMenus(menus)` | `menus: Array<String>` | `void` | 排除指定菜单 |
| `config.colors(colors)` | `colors: Array<String>` | `void` | 自定义颜色列表 |
| `config.fontNames(names)` | `names: Array<String>` | `void` | 自定义字体列表 |
| `config.fontSizes(sizes)` | `sizes: Array<Object>` | `void` | 自定义字号列表 |
| `config.lineHeights(heights)` | `heights: Array<String>` | `void` | 自定义行高列表 |

#### 图片配置

| 方法 | 参数 | 返回值 | 说明 |
|------|------|--------|------|
| `config.uploadImgServer(url)` | `url: String` | `void` | 设置图片上传地址 |
| `config.uploadImgMaxSize(size)` | `size: Number` | `void` | 设置图片大小限制（字节） |
| `config.uploadImgMaxLength(count)` | `count: Number` | `void` | 设置一次最多上传图片数 |
| `config.uploadImgHeaders(headers)` | `headers: Object` | `void` | 设置上传请求头 |
| `config.uploadImgParams(params)` | `params: Object` | `void` | 设置上传额外参数 |
| `config.uploadFileName(name)` | `name: String` | `void` | 设置上传文件字段名 |
| `config.uploadImgHooks(hooks)` | `hooks: Object` | `void` | 设置上传钩子函数 |

#### 视频配置

| 方法 | 参数 | 返回值 | 说明 |
|------|------|--------|------|
| `config.uploadVideoServer(url)` | `url: String` | `void` | 设置视频上传地址 |
| `config.uploadVideoMaxSize(size)` | `size: Number` | `void` | 设置视频大小限制 |
| `config.uploadVideoHeaders(headers)` | `headers: Object` | `void` | 设置上传请求头 |

#### 表格配置

| 方法 | 参数 | 返回值 | 说明 |
|------|------|--------|------|
| `config.insertEmptyTable(fn)` | `fn: Function` | `void` | 自定义插入空表格行为 |

### 使用示例

```js
import E from '@x-apaas/x-wangeditor';

const editor = new E('#editor-container');

// 基本配置
editor.config.placeholder('请输入内容...');
editor.config.zIndex(100);
editor.config.onchange((html) => {
  console.log('内容变更:', html);
});

// 图片上传配置
editor.config.uploadImgServer('/api/upload');
editor.config.uploadImgMaxSize(5 * 1024 * 1024); // 5MB
editor.config.uploadImgHeaders({
  'Authorization': 'Bearer xxx'
});

// 创建编辑器
editor.create();

// 获取内容
const html = editor.html();

// 设置内容
editor.html('<p>Hello World</p>');

// 销毁
editor.destroy();
```
